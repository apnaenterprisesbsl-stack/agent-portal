🔥 Firebase Setup — FREE Real-time Database

1
Browser mein kholein: firebase.google.com → Google account se login karein → Create a project
2
Project naam: "apna-enterprises" → Continue → Create Project (Analytics off kar sakte hain)
3
Left sidebar: Build → Realtime Database → Create Database → Location: Asia (mumbai) → Start in test mode → Enable
4
Database URL copy karein — aisa dikhega:
https://apna-enterprises-default-rtdb.asia-southeast1.firebasedatabase.app
5
Neeche URL paste karein → Save → Done! ✅ Agent portal mein bhi yahi URL use hoga.
✅ Firebase connected! Auto-refresh 30 sec mein hoga. Agent portal mein bhi yahi URL set karein.
📱 Agent Portal Distribute Kaise Karein?
  1. ApnaEnterprises_Agent.html file agent ko bhejein (WhatsApp/USB/Email)
  2. Agent file khole → Agent code enter kare (jo aapne assign kiya)
  3. Firebase URL: Set nahi hai — upar set karein
  4. Agent file mein line var FIREBASE_URL = 'https://apna-enterprises-c20b3-default-rtdb.firebaseio.com' mein apna URL paste karein
  5. Admin portal mein Agents page pe agent add karein (AGT001, AGT002...)
  6. Ab agent ka har transaction aapke Live Feed mein turant dikhega! 🎉
💡 Tip: Auto-refresh 30 seconds mein hota hai. Manual refresh ke liye 🔄 button dabao.
